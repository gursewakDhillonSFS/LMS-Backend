# LMS Backend

NestJS API for the Learning Management System.

## Source of truth

**[docs/BACKEND.md](./docs/BACKEND.md)** — architecture, modules, APIs, auth, Stripe, sockets, env vars, security notes.

Monorepo index: [../DOCS.md](../DOCS.md)

## Quick start

```bash
npm install
# configure .env (see docs/BACKEND.md § Environment Variables)
npm run start:dev
```

```bash
npm run build
```

Typical local URL: `http://localhost:3288` (whatever you set as `PORT`).
